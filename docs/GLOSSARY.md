# Glossary of Terms

Reference for technical terms, acronyms, and concepts used throughout the epi-bic-zoomroom codebase and documentation.

---

## A

### Activation Code
A unique code provided by Zoom that allows the Zoom Room to pair with the Zoom Room infrastructure. Set in the configuration file during device setup.

**Related**: Device pairing, `pairZoomRoom` console command, `ZoomRoomConfiguration.cs`

### AirPlay
Apple's wireless streaming protocol. Used for screen mirroring from iOS/macOS devices. The Zoom Room can receive AirPlay shares.

**Related**: Screen sharing, Share instructions

---

## B

### Beincourt
The courtroom AV system for which this fork was created. Located in a court facility with specific requirements for content sharing with remote participants.

**Related**: [../BEINCOURT.md](../BEINCOURT.md), Fork customization

### Bridge
Short for "SIMPL Bridge". The join map that connects C# device logic to SIMPL+ control system.

**Related**: Join map, ZoomRoomJoinMap.cs

---

## C

### CP4N
Crestron processor (Crestron Processor 4N). The embedded controller running Essentials and plugins. The physical hardware where this plugin executes.

**Related**: Crestron, Essentials, SIMPL+

### Crestron
Crestron Electronics, a manufacturer of control and automation systems. PepperDash is a division of Crestron.

**Related**: Essentials, CP4N, SIMPL+

### .cplz File
Crestron Plugin package (compressed). The compiled plugin binary that gets loaded into CP4N. Contains the compiled C# assembly and resources.

**Format**: ZIP archive containing DLLs, XML metadata, and resources
**Generated by**: GitHub Actions build pipeline
**Deployed via**: PD Tools

**Related**: Artifact, Plugin package, Build output

---

## D

### Device Factory
The component responsible for discovering and instantiating plugin devices. Implements `IDeviceFactory` interface.

**Related**: ZoomRoomFactory.cs, Plugin discovery, Essentials

### Digital Join
A binary (on/off) connection point between SIMPL+ and the C# device. Can carry button presses, toggle states, or indicator LEDs.

**Join Range**: Typically 1-255 (but can extend higher)
**Feedback**: Device to SIMPL+ (e.g., "Microphone Muted" → Digital 15)
**Commands**: SIMPL+ to Device (e.g., "Mute Microphone" ← Digital 25)

**Related**: Join map, Analog join, Serial join

---

## E

### Essentials
PepperDash's open-source framework for building Crestron control systems. Provides base classes, interfaces, and utilities for plugins.

**Version**: v3.0.0+ (this fork uses Essentials v3)
**Framework**: .NET 8
**Repository**: https://github.com/PepperDash/Essentials
**Wiki**: https://github.com/PepperDash/Essentials/wiki

**Related**: Plugin, Device, Join map, Framework

---

## F

### Far-End Camera
Video camera on the opposite side of a Zoom meeting. Opposite of self-view.

**Related**: Self-view, Camera control, Participant roster

### Fork
A copy of a repository maintained independently. This repository is a fork of PepperDash/epi-zoom-room with Beincourt-specific customizations.

**Upstream**: https://github.com/PepperDash/epi-zoom-room
**Fork**: https://github.com/pepperdash-beincourt/epi-bic-zoomroom

**Related**: Repository, Branch strategy, Cherry-pick

---

## G

### GitHub Actions
GitHub's built-in CI/CD system. Automatically builds, tests, and releases code on pushes.

**Usage**: Builds .cplz artifact, runs tests, publishes releases
**Workflows**: Defined in `.github/workflows/`
**Triggers**: Push events to csv-zoom-sandbox branch

**Related**: CI/CD, Workflow, Artifact, Release

### GitHub Packages
GitHub's NuGet repository for hosting private packages. PepperDash publishes packages here.

**URL**: `https://nuget.pkg.github.com/pepperdash/index.json`
**Authentication**: Requires GitHub PAT with `read:packages` scope
**Usage**: Source of PepperDash.ZoomRoom.Sdk

**Related**: NuGet, Package source, Authentication

---

## H

### Host (in meeting)
The person who started or controls a Zoom meeting. Has special permissions like recording, muting others, etc.

**Zoom Room as Host**: When the Zoom Room initiates a meeting
**Participant as Host**: When another person is the meeting host

**Related**: Participant, Role, MeetingInfo, CanRecord

---

## I

### Interface (C#)
A contract defining methods and properties that a class must implement. Used extensively in Essentials.

**Examples**: 
- `IBasicCommunicationDevice`
- `IRoutingInputPort`
- `IHasCodecRoomPresetsActionsMessenger`

**Related**: Implementation, Abstract class, Inheritance

### IRoutingInputPort
Essentials interface that marks a device as a routing source. Allows the device to be selected as a video/audio source.

**Related**: Routing, Source, Essentials interfaces

---

## J

### Join Map
The mapping of SIMPL+ join numbers to C# device methods and feedback. Located in `ZoomRoomJoinMap.cs`.

**Maps**:
- Digital joins → buttons, toggles, indicators
- Analog joins → faders, values
- Serial joins → text, strings

**Purpose**: Bridges SIMPL+ and C# code
**Standard**: Typically digital 1-100, analog 200+, serial 300+

**Related**: Bridge, Digital join, Analog join, Serial join

### JSON
JavaScript Object Notation. Text format for structured data. Used for SDK communication and configuration.

**Example**:
```json
{"volume": 75, "isMuted": false}
```

**Related**: Data format, SDK events, Configuration

---

## L

### Layout
The visual arrangement of video streams in a Zoom meeting. Examples: Speaker (1 large), Gallery (grid), Focus (custom).

**Layouts** (common):
- Speaker: One large participant + thumbnails
- Gallery: Grid of all participants
- Focus: Highlighted participant + one other

**Related**: Screen sharing, Video, Presentation mode

---

## M

### Meeting
An active Zoom conference session. The Zoom Room joins meetings to facilitate remote collaboration.

**States**: 
- Joining → In Call → Leaving → Idle

**Related**: Call, Participant, Roster, MeetingInfo

### Messenger
Essentials component for integrating a device with the Mobile Control app. Each messenger handles a specific feature area.

**Examples**:
- `IHasCameraAutoModeMessenger` - Camera controls
- `IHasParticipantsMessenger` - Participant roster
- `IHasCodecRoomPresetsActionsMessenger` - Presets

**Related**: Mobile Control, Interface, Feature integration

### Microphone Privacy / Mute
State of whether the Zoom Room's microphone is transmitting. When "private" or "muted", audio is not sent to meeting.

**Related**: Audio control, Feedback, Status

### Mobile Control
Crestron's mobile app for controlling AV systems. Plugins can expose features via messengers.

**Related**: Messenger, Essentials, UI/UX

### NuGet
.NET package manager. Like npm for .NET projects. Used to manage dependencies.

**Config file**: `nuget.config`
**Package sources**: nuget.org, GitHub Packages, others
**Authentication**: Often requires PAT or credentials

**Related**: Package, Dependency, Version management

## O

### Outcome
Result of an action or event. Used in logging and diagnostics.

**Related**: Success/Failure, Error handling, Logging

---

## P

### Participant
A person in a Zoom meeting (not the Zoom Room itself). Includes attendees, hosts, co-hosts.

**Info Available**:
- Name
- Role (host, co-host, attendee, panelist)
- Video state (on/off)
- Audio state (muted/unmuted)
- Camera availability

**Related**: Roster, Host, Meeting

### PepperDash
A division of Crestron that creates software and plugins.

**Related**: Crestron, Essentials, Open source plugins

### Plugin
A loadable C# assembly that extends Essentials. This repository IS a plugin.

**Package format**: .cplz (Crestron Plugin archive)
**Discovery**: Via `IDeviceFactory` interface
**Lifecycle**: Loaded by Essentials on startup

**Related**: Device factory, .cplz, Essentials

### PR (Pull Request)
A GitHub feature for proposing code changes. Creates a review and discussion space before merging.

**Process**: Create → Review → Test → Approve → Merge
**Branch Protection**: May require approvals, passing tests before merge

**Related**: GitHub, Branch, Code review

---

## R

### Roster
The list of participants in a Zoom meeting. Updated in real-time as people join/leave.

**Related**: Participant, Meeting, List

---

## S

### SDK (Software Development Kit)
A set of tools and code for interacting with Zoom Room hardware. Provided by Zoom as `PepperDash.ZoomRoom.Sdk` NuGet package.

**Components**:
- Native wrapper library (libzrcsdkwrapperpdt.so)
- Managed C# interface
- Command/response protocol

**Related**: ZrcSdkController, Communication, Protocol

### Self-View
The video feed of the Zoom Room's own camera in a meeting. Shows what the room looks like to remote participants.

**Features**:
- Position (corner, side, etc.)
- Size (small, medium, large)
- Can be hidden during sharing

**Related**: Camera, Layout, Video

### Semantic Release
Automated versioning and release tool. Analyzes commit messages to determine version bumps.

**Versioning**: MAJOR.MINOR.PATCH
- `feat:` → Minor bump
- `fix:` → Patch bump
- `BREAKING CHANGE:` → Major bump

**Configuration**: `.releaserc.json`
**Tools**: Automatic changelog, GitHub Release creation, tagging

**Related**: Release, Versioning, GitHub Actions

### Serial Join
A text communication channel between SIMPL+ and C# device.

**Usage**: Passing strings (device names, contact info, etc.)
**Join Range**: Typically 300+
**Example**: Serial 301 → Device Name feedback

**Related**: Join map, Digital join, Analog join

### Share / Sharing
In Zoom context: Presenting content (screen, window, etc.) to meeting participants.

**Types**:
- Screen sharing: Entire monitor
- Application sharing: Specific window
- HDMI sharing: Content from HDMI input
- Sharing-only meeting: Room shares but doesn't receive video

**Beincourt Detail**: Uses `StartSharingOnlyMeeting()` for far-end focus

**Related**: Content, Presentation mode, StartSharingOnlyMeeting

### SIMPL+ (or SIMPL)
Crestron's programming language for control systems. Runs on CP4N processors.

**Purpose**: Define system logic, interlock control, feedback
**Interaction**: Communicates with plugins via join map
**Features**: Modules, subroutines, system macros

**Related**: CP4N, Join map, Bridge, Control system

### StartSharingOnlyMeeting
Zoom SDK method that starts a "sharing-only meeting" mode. Used by Beincourt for sharing content with remote participants.

**Beincourt Customization**: This fork uses this method instead of `ShareBlackMagic()`
**Reason**: Better for far-end participant focus (courtroom use case)
**File**: `src/ZoomRoom.cs` line ~1251

**Related**: Sharing, Presentation mode, Beincourt customization

## V

### Version

**Channel Suffix**: Development branches have suffix (e.g., "-csv-zoom-sandbox-v2")

### Volume
Audio level of Zoom Room's speaker output. Range typically 0-100 or 0-65535 in SIMPL.

**Related**: Audio control, Feedback, Fader

## Z

### Zoom Room
The physical Zoom Room device being controlled. Hardware made by Zoom for conference room use.

**Capabilities**:
- Camera control
- Microphone/speaker control
- Screen sharing
- Meeting control
- Participant management

**Firmware**: Runs Zoom software
**Integration**: Controlled via SDK by epi-bic-zoomroom plugin

**Related**: SDK, Hardware, Device

### ZoomRoom (Class)
The C# class in this plugin that represents and controls the physical Zoom Room device.

**Location**: `src/ZoomRoom.cs`
**Implements**: Multiple Essentials interfaces
**Purpose**: Main device logic, command routing, state management

**Related**: Plugin, Device, Architecture

### ZoomRoomJoinMap (Class)
The join map class that defines all SIMPL connections for the Zoom Room.

**Location**: `src/ZoomRoomJoinMap.cs`
**Purpose**: Map digital/analog/serial joins to device methods
**Maintainence**: Add new joins here when adding features

**Related**: Join map, Bridge, Integration

### ZrcSdkController (Class)
The controller class that handles low-level SDK communication with Zoom Room hardware.

**Location**: `src/Controller/ZrcSdkController.cs`
**Responsibility**: Send commands, receive events, error handling
**Protocol**: SDK command/response format

**Related**: SDK, Communication, Controller
